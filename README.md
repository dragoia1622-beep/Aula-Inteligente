# Aula Inteligente

Aplicación de aula para la profesora Lenny López. Diseñada por Barrett Tecnología — Sistema DRAGO-IA.

## Abrir la aplicación

1. Descomprime la carpeta.
2. Abre `Aula-Inteligente.html` en el navegador.
3. En **Alumnos**, registra los nombres. En **Lista de cotejo → Editar hoja tipo Excel**, abre la cuadrícula editable.

La aplicación guarda los registros en el navegador. Usa **Copia de seguridad** para guardarlos y restaurarlos al cambiar de navegador, dispositivo o ubicación del HTML. La aplicación intenta cargar Handsontable desde internet y ofrece un formulario alternativo cuando la biblioteca no está disponible.

## Icono de Windows

Abre **Propiedades → Cambiar icono** en el acceso directo y elige `Aula-Inteligente.ico`.

## Repositorio

Sube los archivos de esta carpeta al repositorio. Deja fuera los datos de alumnos y las copias de seguridad reales.
